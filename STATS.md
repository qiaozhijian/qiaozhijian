# Statistics scope

These cards are a manually generated snapshot from 2026-10-10. Automatic updates are not configured.

- Stars include personal public and private non-fork repositories and the co-authored research repositories below. Each repository is counted once. ViPE is displayed in Pinned but its stars are not included in this total.
- Commits cover January 1 to October 10, 2026: public commit contributions plus commits authored by this account on the default branches of personal private non-fork repositories. This is not an all-time commit count or a complete count of every branch and organization.
- PRs and issues count items authored by this account that are visible to the authenticated account, including private items. Reviews use the available 2026 contribution count. Contributed repositories use GitHub's `repositoriesContributedTo` count, excluding personal repositories.
- Language percentages use GitHub language bytes from personal public and private non-fork repositories. The six largest languages are shown and normalized to 100%. Repository contents can include third-party code and document sources; this is not a measure of language proficiency.
- The grade uses the [GitHub Readme Stats formula](https://github.com/anuraghazra/github-readme-stats/blob/master/src/calculateRank.js) with the expanded stars and commits counts above. It is a custom activity score, not an official GitHub grade.
- Only aggregated private statistics are published; private repository names, contents, and credentials are excluded.
